---
title: Overview
description: An Effect v4 SDK for the GitHub CLI.
---

effect-gh wraps the GitHub CLI (`gh`) in Effect v4 services. Each operation runs `gh` without a shell, decodes its output through Schema and fails with a typed error, so you can compose GitHub work with the rest of your Effect program.

```ts
import { NodeServices } from "@effect/platform-node";
import { Effect, Layer } from "effect";
import { Issue, layer } from "@timmo001/effect-gh";

const program = Issue.list({ repo: "owner/repo", state: "open", limit: 10 });

Effect.runPromise(
  program.pipe(Effect.provide(layer().pipe(Layer.provide(NodeServices.layer)))),
);
```
