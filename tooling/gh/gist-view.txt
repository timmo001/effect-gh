$ gh gist view --help
View the given gist or select from recent gists.

USAGE
  gh gist view [<id> | <url>] [flags]

FLAGS
      --allow-escape-sequences[=true|false]   Allow printing terminal escape sequences
  -f, --filename string                       Display a single file from the gist
      --files[=true|false]                    List file names from the gist
  -r, --raw[=true|false]                      Print raw instead of rendered gist contents
  -w, --web[=true|false]                      Open gist in the browser

INHERITED FLAGS
  --help[=true|false]   Show help for command
