$ gh extension upgrade --help
Upgrade installed extensions

USAGE
  gh extension upgrade {<name> | --all} [flags]

FLAGS
  --all[=true|false]       Upgrade all extensions
  --dry-run[=true|false]   Only display upgrades
  --force[=true|false]     Force upgrade extension

INHERITED FLAGS
  --help[=true|false]   Show help for command
