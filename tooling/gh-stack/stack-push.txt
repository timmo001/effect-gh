$ gh stack push --help
Push active branches in the current stack to the remote.

Uses explicit per-branch --force-with-lease checks and atomic updates: all
branch updates succeed or fail together. Use --no-atomic to allow partial updates.
Merged and queued branches are automatically skipped.

Usage:
  gh stack push [flags]

Examples:
  # Push active stack branches to the default remote
  $ gh stack push

  # Push to a specific remote
  $ gh stack push --remote upstream

Flags:
  -h, --help            help for push
      --no-atomic       Disable atomic pushes (also set by GH_STACK_NO_ATOMIC)
      --remote string   Remote to push to (defaults to auto-detected remote)
